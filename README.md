# topology

Данный репозиторий посвящён проекту по использованию различных алгоритмов топологического анализа данных (англ. Topological Data Analysis, TDA) с целью поиска в двумерных наборах данных **гомологий** - пространственных пустот

В качестве рассматриваемых алгоритмов были выбраны:

1. Алгоритм редукции граничной матрицы (англ. boundary matrix) к нормальной форме Смита

2. Алгоритм редукции граничного **списка** к нормальной форме Смита (оптимизация алгоритма №1, позволяющая сократить требуемую память с $O(n^4)$ до $$O(n^2)$$)

3. Алгоритм вычисления пространственных пустот с помощью **когомологий** (модификация оригинального алгоритма)

## Структура репозитория

Проект имеет следующую структуру:

```text
topology/
│
├── tests/
│   └── test_homology.py  # Модульные тесты для проверки корректности алгоритмов
│
├── betti.py              # Класс для расчёта и анализа динамики чисел Бетти
├── exceptions.py         # Исключения и функции валидации входных данных
├── homology.py           # Алгоритмы вычисления гомологий в двумерных данных
├── utils.py              # Вспомогательные декораторы
├── visualization.py      # Модуль визуализации
│
├── topology.ipynb        # Jupyter-ноутбук с примером работы модуля
├── requirements.txt      # Список внешних зависимостей с указанием минимальных версий
└── README.md             # Описание проекта
```

## Инструкция по запуску

Для оптимальной работы проекта достаточно 1-ого CPU

### 1. Установка зависимостей
Перед запуском кода убедитесь, что в вашей среде установлены следующие библиотеки:
```bash
pip install numpy matplotlib scikit-learn scipy ripser persim gudhi tqdm
```

Или же воспользуйтесь альтернативной командой:
```bash
pip install -r requirements.txt
```

### 2. Пример использования модуля
Для запуска экспериментов последовательно запускайте исполняемые ячейки ноутбука `topology.ipynb`
